# distributed-bms
A distributed building management system; all html5; hmi can live on the PLC; all config via yaml; modular; instances can be combined to operate as a fully-fledged SCADA

## Project Status
distributed-bms has progressed beyond the proof-of-concept stage. The core architecture (driver abstraction, configuration model, live updates and HTML client) has been implemented and validated against both simulated devices and real hardware.

Simulator ✔
EMS-ESP ✔
Beckhoff ADS ✔ (prototype)

Decision has been made to develop project in C# and targeting Windows.

## Project development

The project is being developed with the assistance of OpenAI's ChatGPT.

All architectural decisions, software design and source code are reviewed, tested and approved by a human.
